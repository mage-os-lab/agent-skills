# Security policy

## Supported versions

Security fixes are released for the latest minor version. Older versions
receive fixes only when upgrading is not possible within the same major
version.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities by email to **security@mage-os.org**. Include the
module name, the affected version, steps to reproduce and the impact you
expect. You can also use
[GitHub's private vulnerability reporting](../../security/advisories/new)
for this repository.

You can expect an acknowledgement within a few working days. Once a fix is
released, the advisory is published and you are credited unless you prefer
otherwise.
